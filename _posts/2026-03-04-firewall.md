## What is a firewall?

A firewall is a security mechanism that controls network traffic.
Its purpose is to allow or block incoming and outgoing connections based on predefined rules.

## What is it used for?

A firewall is used to:

- protect a system from unauthorized access
- allow only required services
- block unnecessary or dangerous ports
- control network communication

## Basic terms

### Incoming traffic
Traffic coming into the system.

### Outgoing traffic
Traffic leaving the system.

### Port
A logical network endpoint through which a service communicates.

Examples:
- 22 = SSH
- 80 = HTTP
- 443 = HTTPS

### Rule
A rule that determines whether traffic is allowed or denied.

Common actions:
- allow = permit
- deny = block
- reject = refuse
- limit = restrict repeated attempts

## UFW (Uncomplicated Firewall)

UFW is a simple tool for managing firewall rules on Linux systems.

It is used as an easier interface for configuring a firewall without working directly with more complex rule systems.

## Basic UFW commands

### Check status
```bash
sudo ufw allow 22                 # Allow incoming SSH connections on port 22
sudo ufw allow 80                 # Allow incoming HTTP traffic on port 80
sudo ufw allow 443                # Allow incoming HTTPS traffic on port 443
sudo ufw default deny incoming    # Deny all incoming traffic by default
sudo ufw default allow outgoing   # Allow all outgoing traffic by default
sudo ufw enable                   # Enable UFW firewall
sudo ufw status                   # Show current firewall status and active rules
```
